+ Criar uma turma

A turma é a sala: ela tem o código que os alunos usam para entrar. Dentro dela ficam as matérias — a sua e a dos outros professores que dão aula para os mesmos alunos.

+ Entrar numa turma que já existe

Outro professor já abriu a sala? Peça o código dela e crie aqui a sua matéria: vocês passam a dividir os mesmos alunos, cada um com o seu mural.

Receber horas de outro sistema

Gere uma chave para o sistema que vai enviar as atividades já apuradas (exercícios, eventos, monitoria). Ele envia, os alunos aparecem aqui e você valida como sempre.

Guarde agora: a chave aparece uma única vez. Depois só é possível revogar e gerar outra.
